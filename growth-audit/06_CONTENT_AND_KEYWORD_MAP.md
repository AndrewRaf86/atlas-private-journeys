# Content and Keyword Map

Full query-level detail is in `keyword-map.csv`. This file explains the strategy behind it.

## Scoping principle

The original mission brief included broad Peru-wide and Rio/Brazil keyword targets. I've deliberately **not** built a keyword map chasing those yet, for the same reason flagged in `01_BUSINESS_AND_OFFER_AUDIT.md` and `03_COMPETITOR_GAP_ANALYSIS.md`: Atlas has no real Rio content, and broad Peru-wide terms ("private tours Peru," "luxury Peru travel") are owned by 15+ established Tier 1 agencies with a decade-plus head start. Building pages or content for terms Atlas can't credibly win, or can't back with real service, would violate this project's own rule against thin/unsupported pages.

Instead, the keyword map is scoped to what the business can serve **today** (three Lima services) plus a small set of adjacent terms where a genuinely useful, specific page is realistic to write without inventing anything.

## Priority order

**P0 (do first):**
- The three existing service pages already target their core bottom-funnel terms correctly (`private guide Lima`, `Lima airport transfer`, `Lima bachelor party`). The work here isn't new pages — it's getting these pages *indexed* (see `04_SEARCH_VISIBILITY_BASELINE.md`), which no amount of additional content fixes on its own.
- Brand term (`Atlas Private Journeys`) — again, an indexing problem, not a content problem.

**P1:**
- `Lima nightlife guide` — genuine gap. The private-guide page already has a nightlife section and real copy, but there's no dedicated page for this specific, high-interest sub-intent. Worth testing as its own page only once the existing 3 pages are indexed and generating some signal — building a 4th page before the first 3 are even indexed would compound the indexing problem, not solve it.
- `Lima travel concierge` — matches Atlas's honest positioning (see Business Audit) better than "tour" language does. Consider working this phrase into the homepage naturally rather than as a new page.

**P2 and below:**
- Neighborhood-specific variants (Miraflores, Barranco) — reasonable to weave into existing page copy (already partially done on `/private-guide-lima`) rather than spin into separate thin pages.
- `Peru itinerary 7 days` — real opportunity, but only if Atlas can write a genuinely specific sample itinerary reflecting an actual trip Fidel would run, not generic advice that reads like every other blog in the search results for that term. This needs real input (see Owner Decisions) before it's written.

**Explicitly deprioritized (P4):** broad Peru-wide and luxury-positioning terms. Revisit only if Andrew decides to expand real service coverage beyond Lima.

## Content production rule for this project

No new page gets built until it can honestly answer: what does Atlas actually know or offer here that justifies a dedicated page, beyond what's already on an existing page? This is the same standard the original mission brief set ("Do not create a page unless Atlas can provide enough distinct, useful information to justify it") — the keyword map above is filtered through it.
